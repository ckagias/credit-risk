# Credit Risk Prediction

Default prediction on the Home Credit Default Risk data, with the classic ML algorithms compared on one problem, the maths written out in `MATH.md`, and the features built in SQL.

## Data

Home Credit Default Risk, downloaded from Kaggle into `data/raw/` (not tracked).
